  다중 시기 항공영상의 동적 차량 제거를 위한 텍스처 베이킹
                    쉬운 장면, 고점유 장면 및 개선 기준선의 통합 보고서

                                        실험 기록 통합본

              실험: 2026 년 10 월 25–26 일                 문서 작성: 2026 년 10 월 26 일


                                             Abstract

       동일 위치의 다중 시기 사진을 하나의 텍스처로 베이킹할 때 차량 관측을 제외하는 가중치 S
    의 효과를 조사했다. Block-NeRF 형 의미 마스크, NeRF-HuGS 형 일관성 마스크, RobustNeRF
    형 잔차 가중치를 동일한 평면 베이킹에 적용했다. 빈 배경이 다수인 쉬운 장면에서는 미적용 L2
    와 시간 중앙값도 강한 결과를 보였으나, 차량이 다수 시기에 관측되는 두 장면에서는 잔차 선택
    의 실패와 관측 부족이 드러났다. 이에 UV 좌표에서 비차량 관측만 합성하고 미관측 영역을 공
    간 보간하는 기준선 및 마스크 투영ㆍ초기화ㆍ공간 정규화 변형을 비교했다. 그림자 후보 제외를
    추가한 직접 UV 합성은 고점유 차량 위치 PSNR 에서 B 21.00dB, C 22.23dB 를 얻었으며, 기존
    Block 형 대비 각각 약 1.06dB, 1.25dB 높았다. 추가로 같은 관측 선택을 유지한 gradient-domain
    조화와 패치 전사를 비교했으며 지표ㆍ장면에 따라 개선과 악화가 함께 나타났다. 결과는 실제 정
    사사진을 사용하는 반합성 평면 실험에 한정된다. 미관측 배경의 보간과 어두운 잔상이 남아 완
    전한 차량 제거를 뜻하지 않는다.

1     Intro

1.1   문제와 연구 질문

서로 다른 시기에 촬영한 영상 Ii 를 한 장의 텍스처 T 로 모으면 차량 색도 배경에 섞인다. 본 실험
은 메쉬 M 과 카메라 πi 를 고정하고 관측 가중치 Si 를 바꿨을 때, 차량 잔상 억제와 지면 디테일 보
존이 어떻게 달라지는지를 묻는다. 학습 대상은 NeRF 방사장 전체가 아니라 지면 텍스처 및 시점별
색보정이다.
세 단계의 실험은 다음 논리로 연결된다.
1. Easy: 여러 해에 지면이 비고 특정 해에 차량이 많은 장면에서 공통 베이킹과 기존 S 를 검증한
   다.
2. Hard: Easy 에서 L2 도 잘 나온 원인이 빈 관측의 다수 여부인지 확인하기 위해, 차량이 5 회 중
   3–4 회 나타나는 두 실제 장면을 추가한다.
3. Improved: Hard 에서의 실패를 바탕으로, 소수의 비차량 관측을 직접 합성하고 관측 부족에 공
   간 사전정보를 넣는 개선 기준선을 비교한다.


1.2   범위와 용어

Block-NeRF, NeRF-HuGS, RobustNeRF 는 관측 선택의 아이디어를 제공한다 [2, 3, 4]. 이하 “형”
이라는 표현은 본 실험의 베이킹용 구현을 가리키며 원 논문의 전체 NeRF 학습 재현을 뜻하지 않는
다. 제거는 차량 메쉬를 삭제하는 것이 아니라 차량이 찍힌 영상의 색을 텍스처 학습에서 제외하는
것이다. 주차된 정지 차량도 의미 마스크에서는 제거 대상이다.
Easy 문서의 과거 “차량 내부” 는 자동차 실내가 아니다. 실제로는 차체 위치에 둔 반경 5 텍셀 원형
표본이었다. 본 보고서는 이를 차량 위치 표본으로 부르고, Hard 에서는 차량 전체 OBB 영역 평가
와 명확히 구분한다.

2.3   L2 / no-removal: 모든 관측을 사용

                                           SiL2 (r) = 1.                                     (2)

차량 여부를 판단하지 않고 모든 유효 관측의 L2 오차를 줄인다. 같은 위치에 빈 배경이 많이 보이면
차량색이 희석되지만, 차량이 다수 시기에 보이면 그 색이 텍스처에 남는다. 이 기준선은 별도의 제
거 기법을 적용하지 않은 베이킹이다.

2.4   Block 형: 차량 클래스이면 관측을 제외

검출 마스크 Di (r) 를 차량이면 1, 아니면 0 으로 정의한다.

                                SiBlock (r) = 1 − Di (r).                (3)

즉 차량 검출 → 차량 픽셀 제외 → 같은 L2 베이킹이다. DOTA YOLO11s-OBB 의 small/large
vehicle 검출 (confidence0.25) 을 polygon 으로 채우고 5×5 팽창해 Di 를 만든다. S 는 학습 중 고정
한다. 원 Block-NeRF 의 Panoptic-DeepLab 을 항공영상용 검출기로 바꾼 베이킹 구현이며, 그림자
를 별도로 제외하지는 않는다.


2.5   HuGS 형: 정적으로 일관된 영역만 사용

HuGS 형은 정적 후보를 만들고 SAM 영역별로 확장해 S 를 고정한다. 먼저 특징점이 반복 관측되
는 영역 Fi 와 L2 warm-up 잔차가 작은 영역 Ci 를 합치고, 큰 잔차를 제한하는 Qi 로 걸러 정적 후
보를 만든다.
                           Hi = (Fi ∪ Ci ) ∩ Qi .             (4)
이 식의 Hi 는 핵심 결합 구조를 뜻하며, 구현에서는 여기에 국소 다수결 보정을 적용한다. Fi 는 20
개 입력 중 자기 자신 포함 5 개 이상에서 검증된 특징점의 SAM 영역, Ci 는 warm-up 잔차 평균 이
하 영역이다. Qi 는 95 분위수 이하 영역에 Ci 를 합친 제한 영역이다.

3.5   관측 선택의 시각화: 빨간색은 제외한 관측 S=0

수식의 S 가 실제로 어느 픽셀을 제외하는지 확인하기 위해 입력 사진에 마스크를 겹쳐 표시했다.
세 장면 모두 2025 년, 기울기 20 도 카메라, seed42 의 저장 마스크를 사용했다. 빨간색은 valid 중
S < 0.5 인 제외 관측이며, 회색은 지면 투영의 valid 밖이다. 패널의 제외 비율은 해당 입력의 valid
전체에서 계산한 값으로 평가 ROI 비율과 다르다. 같은 장면의 모든 패널은 동일한 입력ㆍ카메라ㆍ
색 범위를 공유한다.
L2 는 차량도 사용하므로 빨간 영역이 없다. Block/HuGS 는 학습 전 고정한 선택, Robust 계열은
최종 텍스처에서 재계산한 선택의 스냅샷이다. Robust 의 빨간색은 학습 전체에서 한 번도 사용하
지 않은 영역이라는 의미가 아니다. Geometry mask/init/prior 는 같은 S 를 공유하므로 하나의 패
널로 표시했다. UV fusion 의 패널은 원본 UV 관측 선택을 같은 카메라로 투영한 것으로, 직접 합성
이 별도 렌더 손실을 학습한다는 뜻은 아니다.

3.6   해석, 한계 및 재현 범위
1. 관측 선택의 효과: 잔차가 작다는 사실과 정적 배경이라는 사실은 다르다. 의미 마스크로 차량 관
   측을 제외하면 소수 배경도 사용할 수 있지만 검출 누락은 그대로 영향을 준다.
2. 복원과 보간의 구별: 5 회 모두 가린 영역은 색을 직접 관측하지 못했다. 조화 보간ㆍ TV ㆍ
   anchor 는 공간적 추정으로, 실제 배경의 정확한 복원을 입증하지 않는다. 차선과 작은 디테일 손
   실도 남는다.
3. 공 정 성 의 범 위: 학 습 형 은 동 일 600 회 ㆍ 동 일 Adam 설 정 이 지 만 HuGS 는 추 가 warm-
   up/SIFT/SAM 비용이 있다. 직접 fusion 은 최적화가 없고 학습형 aﬀine 색보정도 없으므로 계산
   비용ㆍ모델군까지 같지는 않다. 원 중앙값 참고 기준선은 512 기저도 거치지 않았다.
4. 통계와 평가: 3seed 의 표준편차는 동일 장면의 최적화 변동이며 독립 3 장면이나 신뢰구간이 아
   니다. Hard 주평가는 B4 개, C17 개로 작고 불균형하다. detector 기반 위치ㆍ점유와 실제 2026
   년의 조명ㆍ토양ㆍ계절 변화에 따른 편향이 남는다.
5. 설계와 일반화: Improved 는 같은 benchmark 의 이전 실패를 보고 설계했다.2026 RGB 나
   annotation 을 fusion ㆍ최적화에 쓰지는 않았지만 외부 미관측 데이터 검증으로 해석할 수 없다.
   반합성 카메라는 실제 사선 촬영의 3D parallax 가 없고, 두 Hard 장면도 같은 산업지구다.
현재 조건의 실용적 기준선은 비차량 UV fusion 이며, 어두운 흔적을 줄이려면 고정 shadow guard
를 함께 비교할 수 있다. 전체 차량 제거의 보증이 아닌 개선된 출발점이다. 본 통합 문서는 저장된
실험을 재정리한 것이며 새 학습이나 평가 영역 변경은 수행하지 않았다.
